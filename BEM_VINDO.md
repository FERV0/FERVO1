## 🤔 Perguntas Frequentes

### Preciso saber programar?
Não! Para personalizar textos, fotos e vídeos, basta seguir o guia.
Para mudanças mais avançadas, conhecimento de React/TypeScript ajuda.

### Posso mudar as cores?
Sim! Edite `tailwind.config.ts` e mude a paleta de cores.

### Como adiciono fotos?
1. Coloque as fotos em `public/photos/`
2. Edite `src/app/fotografia/page.tsx`
3. Adicione ao array de fotos

### Como faço deploy?
Leia o [DEPLOY.md](DEPLOY.md) - tem guias para Vercel, Netlify e outras plataformas.

### O site é gratuito para hospedar?
Sim! Vercel e Netlify têm planos gratuitos generosos.

### Posso vender este projeto?
Sim! O código é seu para usar como quiser.

## 🛠️ Suporte

### Problemas Comuns:

**Porta 3000 já em uso?**
```bash
netstat -ano | findstr :3000
taskkill /PID [número] /F
npm run dev
```

**Erro de instalação?**
```bash
rm -rf node_modules
npm install
```

**Site não atualiza?**
```bash
# Pare o servidor (Ctrl+C)
rm -rf .next
npm run dev
```
