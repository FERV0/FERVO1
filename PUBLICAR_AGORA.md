## 📋 PASSO A PASSO SIMPLES

### PASSO 1: Instalar Git (Se ainda não instalou)

1. **Baixe:** https://git-scm.com/download/win
2. **Execute o instalador**
3. **Deixe tudo padrão** (apenas clique Next)
4. **Reinicie o computador** após instalação

### PASSO 2: Publicar o Site

**Opção A - Modo Fácil (Recomendado):**

1. **Clique duas vezes** no arquivo: `1-PUBLICAR-NO-GITHUB.bat`
2. **Aguarde** a execução
3. **Pronto!** 🎉

**Opção B - Modo Manual:**

Abra o PowerShell nesta pasta e execute:

```powershell
git init
git add .
git commit -m "Initial commit - Site FERVO"
git branch -M main
git remote add origin https://github.com/FERV0/FERVO1.git
git push -u origin main
```

### PASSO 3: Ativar GitHub Pages

1. Acesse: **https://github.com/FERV0/FERVO1**
2. Clique em **Settings** (Configurações)
3. No menu lateral, clique em **Pages**
4. Em **Source**, selecione: **GitHub Actions**
5. **Pronto!** Deploy automático está ativado

### PASSO 4: Aguardar Deploy

1. Vá na aba **Actions** do repositório
2. Você verá o deploy acontecendo (bolinha amarela girando)
3. Aguarde **2-5 minutos**
4. Quando ficar **verde**, o site está no ar!

### PASSO 5: Acessar Seu Site

**URL do seu site:**
```
https://ferv0.github.io/FERVO1/
```

## ❓ PROBLEMAS COMUNS

### "git não é reconhecido"
**Solução:** Instale o Git e reinicie o computador

### "Permission denied" ou "Authentication failed"
**Solução:** 
1. O GitHub vai pedir suas credenciais
2. Use seu **nome de usuário** e **senha** do GitHub
3. Se não funcionar, use **Personal Access Token**:
   - Acesse: https://github.com/settings/tokens
   - Gere um novo token
   - Use o token como senha

### "Site não carrega" ou "404"
**Solução:**
1. Verifique se GitHub Pages está ativado
2. Aguarde 5 minutos
3. Limpe cache do navegador (Ctrl + Shift + Delete)
4. Tente em modo anônimo

### "Deploy falhou"
**Solução:**
1. Vá em **Actions** no GitHub
2. Clique no deploy que falhou
3. Veja os logs de erro
4. Geralmente é problema de configuração do Pages

## 💡 DICAS

### Para Adicionar Fotos na Galeria:

1. Coloque as fotos em `public/photos/`
2. Edite `src/app/galeria/page.tsx`
3. Adicione no array de fotos
4. Execute: `2-ATUALIZAR-SITE.bat`

### Para Adicionar Foto do CEO:

1. Coloque a foto em `public/ceo/ceo-photo.jpg`
2. Edite `src/app/mural-ceo/page.tsx`
3. Siga instruções em `public/ceo/README.md`
4. Execute: `2-ATUALIZAR-SITE.bat`

### Domínio Personalizado:

Se quiser usar um domínio próprio (ex: `fervoficial.com.br`):

1. No GitHub Pages, adicione em **Custom domain**
2. Configure DNS do domínio:
   - Tipo: `CNAME`
   - Nome: `www`
   - Valor: `ferv0.github.io`
